  What it does
  - Data: the PDF text parsed to 780 scenarios, with Mastermind, Scheme, Villain
    groups, Henchmen, Heroes, Notes and PDF page. It covers 9 sections (Golden
    Age through 2010s, Marvel Noir, Secret Wars 2015). 173 are Solo.
  - Browser: a new Scenarios button in the left bar opens the panel. You can
    search by title, hero, villain, Mastermind or Scheme, filter by era and Solo
    only, and filter to what the pools hold now.
  - Row colours: yellow means an expansion is off. Red means a card is not in
    this library.
  - Set up scenario:
    - It switches on any expansion the scenario needs.
    - It picks the player count from the lists: Solo or 3 Heroes means 1 player,
      otherwise it follows the Villain and Henchmen group counts.
    - It sets the Mastermind and Scheme.
    - It makes setup() draw exactly the listed Heroes, Villain groups and
      Henchmen.
  - Fallbacks: if a card is missing, Set up stops and names it, and Set up 
    anyway fills the gap at random. Normal Setup is unchanged.
  - Card text: opens the Scheme's reference text.
  - Library audit: counts how many scenarios are ready, need an expansion, or
    are not possible.

  What this library can actually run
  With every expansion on, 278 of 780 scenarios are fully playable, 47 of them
  Solo. The rest name cards this mod does not contain. The most common:
  - Heroes: Peter Parker Homecoming (38), Deadpool Mercs for Money (26), Tony
    Stark (23), Magneto (22), Sabretooth (16), Loki (14).
  - Henchmen groups: Hammer Drone Army (26), SHIELD Assault Squad (23),
    Asgardian Warrior (21), Cops (19).
  - Villain groups: Chitauri (27), Avengers (25), Iron Foes (18).
  - Schemes and Masterminds: about 38 Schemes and 49 Masterminds that the mod
    lacks.

  This extends your earlier list of 10 missing library cards, and it is a gap in
  the cards, not a fault in the browser.

  Limits
  - Custom Villain Decks: 34 scenarios build the deck from individual cards of
    several groups ("Moonstone's Gang (Blackout x2…)"). The browser shows the
    lists and refuses to auto-set them up.
  - Notes: anything besides "Solo" (extra Hero in the Villain Deck, Villain Mat,
    KO pile tricks) is a manual step shown in the detail. I did not automate
    it.
  - Name matching: names match with case, punctuation, "&" and "the" ignored. I
    added aliases only where the deck tags prove the match (Wolverine X-Men is
    Core Wolverine, Beast Illuminati is the Secret Wars V2 Beast) and for typos
    in the PDF. Ambiguous ones like Peter Parker Homecoming stay unmatched,
    because a wrong alias would silently draw the wrong Hero.
